## 直接開啟

用 Chrome、Edge 或 Safari 開啟 `folio-preview-v4.html`。不需安裝套件、登入或連接網絡。

- 首頁預設為「我的持倉」，不自動載入示範。
- 「設定 → 查看示範資料」提供 8 筆示範紀錄，包括股票、債券、基金、保險、存款證、雙標的掛鈎票據及一筆歷史已結清股票。
- 示範與自己的組合分開，切換不覆蓋自己的持倉；重開示範會重設示範修改。
- 單檔 HTML 的持倉只在本次頁面保留，重新整理或關閉後清除。請在設定匯出 JSON，下次開啟後再匯入。
- 自訂系統名稱屬瀏覽器偏好，會在瀏覽器允許時保存，並更新側欄、頁尾、標題及匯出檔案名稱。
- 所有數據及匯率手動輸入，未連接即時行情。示範價格不是市場報價。

請將下載檔案另存備份，避免只依賴對話中的臨時下載連結。

## 本機保存模式

需要 **Node.js 22.13 或以上**。沒有第三方依賴，不需要 `npm install`。

解壓後在 `folio` 資料夾內開啟終端機：

```sh
node build.mjs
node local-server.mjs
```

開啟 `http://127.0.0.1:4173`。資料存於本機 `.local/portfolio.sqlite`，可跨重新整理及程式重啟保存。伺服器只監聽本機地址，按 Ctrl+C 停止。請自行備份 `.local`，不要將其提交 GitHub。

舊版 `.local/portfolio.sqlite` 使用相同 `portfolios` 資料表、`local-owner` 使用者及欄位。升級前先備份原檔，再保留此資料夾。更便捷的方式是從舊版匯出 JSON，在新版本匯入。

## 第四版功能

### 總盈虧包括歷史已結清盈虧

- 目前持倉盈虧 = 港元現值 − 港元成本 + 已收收益 − 費用。
- 歷史已結清盈虧 = 港元結清金額 − 歷史成本 + 已收收益 − 費用。
- 首頁「持倉總盈虧」為上述兩部分之和，並分列兩部分。
- 累計回報率 = 總盈虧 ÷ 目前及歷史所有紀錄的投入成本。

回收本金不當作盈利，也不重複加入目前市值。「累計投入成本」包括所有紀錄；資金重複運用會重複計入不同紀錄的成本，因此是簡單紀錄回報，不是年化、TWR、IRR 或資金加權報酬。零成本時不顯示百分比。

目前市值、配置、風險及壓力試算只計目前持倉。歷史沽出款項不自動成為目前資產；歷史價格與匯率必須填入實際結清資料。

### MOP 澳門元

持倉、匯入匯出、貨幣曝險與計算均支援 MOP。匯率填「1 MOP 兌多少 HKD」，投入和估值／結清時分開填寫。選擇非港元幣種時必須輸入匯率，不會假定 MOP 與 HKD 等值。

### 類別集中度

在首頁資產配置點「股票」，或點持倉明細的股票分頁，可看目前股票集中度；其他類別同樣適用。

- 圖表按港元市值排序，顯示每個標的佔該類資產、以及佔整體目前資產的比例。
- 同名標的合併不同批次，忽略名稱中的空白及英文大小寫；不同幣種先折算港元。
- 同一標的請用一致名稱；不同名稱不會自動辨認為同一隻股票。
- 類別內佔比超過 25% 時提示；這是預設提示線，不是個人化投資上限。
- 圖表分母不受表格搜尋、風險篩選或歷史分頁影響，始終只計該類別的全部目前持倉。
- 無持倉或零市值時不顯示誤導百分比。基金與掛鈎票據不穿透底層持股。

## 其他已保留功能

### 價格、股數／份數及投資起始日

股票、基金：買入價 × 數量為成本；現價 × 同一數量為現值。多次買入可以填加權平均買入價，或分別新增不同批次。

債券支持「每份全價 × 份數」及「每 100 面值全價 × 總面值 ÷ 100」。例如價格 98.25、總面值 50,000，成本為 49,125。全價須包含應計利息。

保險填可退保價值，不是保額；存款證填含應計利息估值；掛鈎票據填發行人提供的估值。已計入估值的收益不可重複計入已收收益。

起始日不可晚於估值日，沽出日／到期日不可早於起始日。舊紀錄缺少日期或單位價格時保留原金額並標示待補，不推算杜撰歷史資料；編輯時需補齊。

### 一至兩個掛鈎標的

每張票據可輸入 1–2 個不同港股／美股標的，記錄名稱、市場、代號、現價與障礙價。代號重複會被拒絕。現價與障礙價須同時填寫或同時留空。

障礙距離 =（現價 − 障礙價）÷ 障礙價。僅比較目前輸入價格，不判定過往觸發、觀察日、最差表現或實物交收條款。

### 歷史持倉

沿用已確認規則：**UTC 今天已超過沽出日／到期日，即填寫日期早於今天時，轉入歷史持倉；日期為今天、未來或留空仍是目前持倉。**

提供目前／歷史／全部分頁。日期分類在載入及跨日時自動更新，不刪除原紀錄。歷史頁按記錄顯示成本、結清金額及盈虧。部分沽出需拆分為已結清及仍持有兩筆紀錄。

### 設定與備份

設定提供 JSON 完整備份、CSV 匯出，以及 JSON／CSV 匯入。相容本次對話第二至第四版的欄位；JSON 使用 `format: folio-portfolio`、`version: 1`，每筆持倉使用 `schemaVersion: 2`。

- 匯入先預覽，再選擇合併或取代。
- 合併保留原紀錄，相同編號略過；要完整還原修改請使用取代。
- 取代需在畫面勾選確認，會移除備份未包含的原紀錄。
- JSON 系統名稱還原為選填。
- 上限 2 MB／1,000 筆，無效檔案不部分寫入。
- 舊 CSV 沒有持倉編號，每次匯入視為新紀錄，重匯可能重複。
- 示範模式匯入只影響示範組合。

## 原始碼

- `public/index.html`、`style.css`、`app.js`：畫面及互動。
- `public/model.js`：共用計算、日期分類、風險、驗證、示範與集中度。
- `public/transfer.js`：JSON／CSV 匯入、匯出與合併。
- `preview.mjs`：產生可直接開啟的單檔 HTML。
- `build.mjs`：產生本機服務資源。
- `local-server.mjs`：本機 HTTP 與 SQLite 保存。
- `worker.js`：可測試的資料 API 與靜態回應；不含已設定的雲端部署。
- `check.mjs`：計算與資料功能檢查。

重新產生單檔：

```sh
node preview.mjs folio-preview-v4.html
```

包內不含網站身份、憑證、使用者持倉或 Git 遠端設定。若後續使用 GitHub Pages，單檔 HTML 可作靜態預覽；GitHub Pages 本身不執行 Node.js／SQLite，持久保存須另行安排。
